# 32项完整配对数据说明

## 这是什么

`raw`是Sysplorer仿真结果导出的时序CSV。“32项配对”表示项目内部选定32个回归场景，每个场景分别保存当前正式主算法`RA-GCA-CGHTE`和上一版`RA-GCA/V8`的结果，共64个CSV。

## 为什么放在这里

这些数据用于：

- 复算阶跃、轨迹、参数摄动、风扰、传感器和编队指标。
- 追溯当前主算法与V8的同条件差异。
- 为后续报告、用户手册、开发文档和可视化提供唯一数据来源。

它们位于补充证据区，不是评委理解项目的第一入口，也不是A8官方规定必须有32个场景。

## 如何理解结果

`campaign_pairs.csv`的32行均通过配对门，表示同一场景的数据对应关系、物理门和预设比较项通过。完整决选评价中的高标准参数保持比总门仍为未通过。因此数据不能单独支撑“全部决选门通过”或“所有指标全面优于V8”的结论。

`RAW_MANIFEST.json`记录两侧文件名、大小和SHA256。原始数值未因正式算法命名而改写；历史来源别名只允许在来源清单中出现。
